---
This is my ongoing research at WPI, guided by Prof. Nitin Sanket, on active perception for drone navigation using low power ultrasound sensors. The sensor setup contains a steerable component for focused perception and look-ahead. The navigation stack is driven using an RL Policy.

I also built a sensor simulation setup for the ultrasound sensor in Isaac Sim using ray tracing and kWave simulation data. Alongside this, I designed and simulated custom acoustic horns to be fitted on the ICU 30201 low power ultrasonic sensor.
